# MoodTunes

An engaging web app that uses your webcam to analyze your facial expression and generates a personalized music playlist matching your current mood. Like a digital mood ring for music!

Key Features:
- Real-time emotion detection using face-api.js
- Animated mood visualization
- AI-curated playlist generation
- Share your mood & playlist on social media
- Daily mood tracking statistics

Tech Stack:
- face-api.js for facial emotion detection
- Web Audio API for sound visualization
- LocalStorage for mood history
- Responsive design works on all devices
